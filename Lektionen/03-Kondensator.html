Lektion 3 · Der Kondensator

Kapazität → Dielektrikum → Schaltungen → Energie → Laden und Entladen über einen Widerstand. Grundlage: Hefteinträge (12.1) Elektrodynamik, Klausur 2 (13.11.2025) Aufgaben 1, 2, 4, Abitur 2016 I und 2023 IIa aus der Mappe.

Lernziele

  • Kapazität als Ladung pro Spannung verstehen, aus Messwerten bestimmen, \(C = \varepsilon _{0}\cdot \varepsilon _{r}\cdot A/d\) herleiten und anwenden.
  • Dielektrikum erklären (Polarisation, Gegenfeld) und die beiden Fälle „Quelle angeschlossen" / „Quelle getrennt" unterscheiden.
  • Reihen- und Parallelschaltung herleiten und gemischte Schaltungen rechnen (Klausur 2, Aufgabe 4).
  • Energie \(W = \tfrac{1}{2}\cdot C\cdot U^{2}\) begründen.
  • Entlade- und Ladekurve: Differenzialgleichung aufstellen und lösen, \(\tau = R\cdot C\), Halbwertszeit, Regression in die e-Form umrechnen, Ladung als Fläche unter \(I(t)\) (Klausur 2, Aufgabe 1).

Rote Kästen = so fragt die Klausur (mit echten Punkten). Orange Kästen = Verwechslungsgefahr und Fehler, die schon Punkte gekostet haben.

Nachtrag zu Lektion 2 (steht so in der Mappe): Das Potenzial einer Punktladung ist \(\varphi (r) = Q/(4\pi \varepsilon _{0}\cdot r)\) (FS S. 26) mit der Vereinbarung \(\varphi (\infty ) = 0\). Flächen gleichen Potenzials (Äquipotenzialflächen, bei der Punktladung Kugeln) stehen senkrecht auf den Feldlinien; entlang einer solchen Fläche wird keine Arbeit verrichtet. Beispiel aus dem Heft: Im Erdfeld mit \(E = 130\,\mathrm{V/m}\) liegt zwischen zwei Punkten in \(1\,\mathrm{m}\) Höhenunterschied eine Spannung von \(130\,\mathrm{V}\).

1 · Kapazität

Definition: Ladung pro Spannung

Ein Kondensator ist technisch gesehen ein Ladungsspeicher. Lädt man ihn mit der Spannung \(U\), sitzt auf jeder Platte die Ladung \(Q\) (eine positiv, eine negativ). Versuch der Mappe: Kondensator über einen Umschalter mit \(U\) laden, dann über einen Messverstärker entladen und \(Q\) messen. Ergebnis: \(Q \propto U\), die Punkte im \(Q\)-\(U\)-Diagramm liegen auf einer Ursprungsgeraden. Die Steigung ist die Kapazität:

\[C = \frac{Q}{U},\qquad [C] = 1\,\mathrm{\frac{C}{V}} = 1\,\mathrm{F}\ (\text{Farad}) = 1\,\mathrm{\frac{As}{V}}\]
  • Die Kapazität sagt, wie viel Ladung der Kondensator pro Volt speichert. Sie hängt nur von der Bauform ab (Fläche, Abstand, Füllmaterial), nicht von \(Q\) oder \(U\).
  • \(1\,\mathrm{F}\) ist riesig. Technische Kondensatoren: \(\mathrm{pF}\) (\(10^{-12}\)) bis \(\mathrm{mF}\) (\(10^{-3}\)). Umrechnen üben: \(220\,\mathrm{nF} = 2{,}2\cdot 10^{-7}\,\mathrm{F}\), \(44\,\mathrm{\mu F} = 4{,}4\cdot 10^{-5}\,\mathrm{F}\).
  • Einsatzmöglichkeiten (Abitur 2016, 4 BE): Kurzzeit-Energiespeicher im Blitzgerät (schnell viel Ladung abgeben), Goldcap als Energiespeicher für die Fahrradbeleuchtung im Stand, Glättung von Spannungen in Netzteilen, Zeitglied in Schaltungen (RC-Glied), Sensor (Füllstandsanzeiger, Touchscreen).

Woher kommt \(C = \varepsilon_0\cdot A/d\)? (Herleitung aus dem Heft)

  1. Flächenladungsdichte \(\sigma = Q/A\): Ladung pro Plattenfläche. Versuch: feste Platten (\(A = 0{,}047\,\mathrm{m^2}\), \(d = 1\,\mathrm{cm}\)), \(U\) variieren, \(Q\) messen, \(E = U/d\) und \(\sigma = Q/A\) berechnen. Das \(\sigma\)-\(E\)-Diagramm ist eine Ursprungsgerade: \(\sigma \propto E\). Die Steigung ist eine Naturkonstante, die elektrische Feldkonstante: \(\sigma = \varepsilon _{0}\cdot E\) mit \(\varepsilon _{0} = 8{,}854\cdot 10^{-12} \,\mathrm{As/(Vm)}\) (steht in der FS S. 26 als \(\sigma = \varepsilon _{0}\cdot \varepsilon _{r}\cdot E\)).
  2. Einsetzen: \(Q/A = \varepsilon _{0}\cdot U/d\).
  3. Mit \(Q = C\cdot U\): \(C\cdot U/A = \varepsilon _{0}\cdot U/d\) ⇒ \(C = \varepsilon _{0}\cdot A/d\). Mit Füllmaterial kommt \(\varepsilon _{r}\) dazu (Abschnitt 2).
\[C = \varepsilon_0\,\varepsilon_r\,\frac{A}{d}\qquad(\text{Plattenkondensator; } A = \text{Fläche einer Platte, } d = \text{Abstand})\]

Abhängigkeiten, die man begründen können muss: große Fläche → mehr Platz für Ladung → \(C \propto A\). Kleiner Abstand → bei gleichem \(Q\) ist \(U = E\cdot d\) kleiner → \(C = Q/U\) größer → \(C \propto 1/d\) (antiproportional). Im Abitur 2023 wurde genau das aus Diagrammen abgefragt: im \(C\)-\(d\)-Diagramm eine Hyperbel, im \(C\)-(\(1/d\))-Diagramm eine Ursprungsgerade mit Steigung \(\varepsilon _{0}\cdot A\), daraus \(\varepsilon _{0} = \text{Steigung}/A\).

\(Q\)-\(U\)-Diagramm: Steigung = \(C\). Die schraffierte Fläche unter der Geraden bis zur eingestellten Spannung ist die gespeicherte Energie \(W = \tfrac{1}{2}\cdot Q\cdot U\) (Abschnitt 4).

Rechenbeispiel (Klausur 2, 2b)

\(A = 0{,}1\,\mathrm{m^2}\), \(d = 6\,\mathrm{cm}\), Luft: \(C_{0} = \varepsilon _{0}\cdot A/d = 8{,}854\cdot 10^{-12} \,\mathrm{As/(Vm)} \cdot 0{,}1 \,\mathrm{m^2} / 0{,}06 \,\mathrm{m} = 1{,}48\cdot 10^{-11} \,\mathrm{F} = 14{,}8 \,\mathrm{pF}\). Einheiten-Check: \(\mathrm{As/(Vm)}\cdot \mathrm{m^2/m} = \mathrm{As/V} = \mathrm{F}\).

Typische Fehler: \(d\) in \(\mathrm{cm}\) statt \(\mathrm{m}\). \(A\) in \(\mathrm{cm^2}\) statt \(\mathrm{m^2}\) (\(1\,\mathrm{cm^2} = 10^{-4}\,\mathrm{m^2}\), \(400\,\mathrm{cm^2} = 0{,}04\,\mathrm{m^2}\)). Zehnerpotenzen bei \(\mathrm{pF/nF/\mu F}\). Und: \(C\) ändert sich nicht, wenn man \(U\) ändert, nur \(Q\) ändert sich mit.

2 · Das Dielektrikum

Was passiert, wenn man einen Isolator zwischen die Platten schiebt?

  1. Das Feld \(E\) der Platten polarisiert den Isolator: In jedem Molekül verschiebt sich die Elektronenhülle ein Stück gegen die Feldrichtung, die Moleküle werden Dipole (Lektion 1).
  2. An der Oberfläche des Isolators bleibt netto Ladung übrig: zur positiven Platte hin negativ, zur negativen Platte hin positiv. Diese Oberflächenladungen erzeugen ein eigenes Feld \(E_{p}\), das dem Plattenfeld entgegengerichtet ist.
  3. Gesamtfeld im Isolator: \(E_{\mathrm{ges}} = E - E_{p} < E\). Das Feld wird um den Faktor \(\varepsilon _{r}\) geschwächt: \(E_{\mathrm{ges}} = E/\varepsilon _{r}\).
  4. Bei gleicher Ladung \(Q\) ist die Spannung \(U = E_{\mathrm{ges}}\cdot d\) kleiner, also \(C = Q/U\) größer: \(C = \varepsilon _{r}\cdot C_{0}\). Im Heft: \(Q = \varepsilon _{r}\cdot \varepsilon _{0}\cdot A\cdot E\).

\(\varepsilon _{r}\) heißt relative Permittivität (Dielektrizitätszahl), eine Materialkonstante ohne Einheit: Vakuum 1, Luft ≈ 1, Gips 1,8, Öl 2,2, Paraffin 2,3, Polystyrol 2,6, Plexiglas 3,4, Porzellan 4,5–6,5, Silicium 12, Glycerin 43, Wasser 81 (Tabelle M3 aus dem Abitur 2016). \(\varepsilon _{0}\) ist die Permittivität des Vakuums.

Grün: Feld der Platten. Blau: Gegenfeld der Polarisationsladungen. Stärkeres \(\varepsilon _{r}\) → mehr Gegenfeld → schwächeres Gesamtfeld.

Verwechslungsgefahr, die zwei Fälle:
Quelle getrennt (Kondensator geladen, dann abgeklemmt): \(Q\) bleibt, weil die Ladung nirgends hin kann. Dielektrikum rein → \(C\) steigt → \(U = Q/C\) sinkt. Abstand vergrößern → \(C\) sinkt → \(U\) steigt (Abitur 2023, 3.4).
Quelle angeschlossen: \(U\) bleibt (die Quelle hält sie). Dielektrikum rein → \(C\) steigt → \(Q = C\cdot U\) steigt, es fließt Ladung nach. Erst klären, welcher Fall vorliegt, dann rechnen.

Teilweise gefüllter Kondensator = Parallelschaltung (Klausur 2, 2d; Abitur 2016, 1.1 und 1.3)

Platten der Höhe \(h\) stehen bis zur Höhe \(f\) im Öl. Der untere Teil ist ein Kondensator mit Öl, der obere ein Kondensator mit Luft. Beide haben dieselbe Spannung (es sind dieselben Platten), ihre Ladungen addieren sich → Parallelschaltung, Kapazitäten addieren sich. Jeder Teil hat seinen Flächenanteil:

\[C(f) = C_0\,\frac{h-f}{h} + C_{\mathrm{Öl}}\,\frac{f}{h}\quad\Rightarrow\quad f(C) = h\cdot\frac{C - C_0}{C_{\mathrm{Öl}} - C_0}\]

Bei links/rechts geteilten Materialien (Abitur 2016, M1: oben Material 2, unten Material 1, je halbe Fläche) genauso: \(C = C_{1} + C_{2} = \varepsilon _{0}\cdot \varepsilon _{r1}\cdot (A/2)/d + \varepsilon _{0}\cdot \varepsilon _{r2}\cdot (A/2)/d\), aufgelöst \(\varepsilon _{r1} = 2\cdot C\cdot d/(A\cdot \varepsilon _{0}) - \varepsilon _{r2}\). Das war die Gleichung im Abitur. Begründung in der Klausur: gleiche Spannung an beiden Teilen, Flächenanteile.

Das kostete in Klausur 2 die Punkte (2d, 0/3): nicht erkannt, dass der halb gefüllte Kondensator zwei parallele Teilkondensatoren sind. Merksatz: Material nebeneinander (Teile sehen beide Platten) = parallel. Material hintereinander (Schichten zwischen den Platten) = Reihe.

3 · Reihen- und Parallelschaltung

Parallel: Kapazitäten addieren

Beide Kondensatoren liegen an derselben Spannung \(U\). Jeder speichert seine Ladung: \(Q_{1} = C_{1}\cdot U\), \(Q_{2} = C_{2}\cdot U\). Die Gesamtladung ist die Summe:

\(Q_{\mathrm{ges}} = Q_{1} + Q_{2}\) ⇒ \(C_{\mathrm{ges}}\cdot U = C_{1}\cdot U + C_{2}\cdot U\) ⇒

\[C_{\mathrm{ges}} = C_1 + C_2\]

Anschaulich: Parallelschalten = Plattenfläche vergrößern. Die Gesamtkapazität ist größer als jede einzelne.

Reihe: Kehrwerte addieren

Die Ladung ist bei beiden gleich (die mittlere Verbindung ist isoliert, dort wird nur Ladung verschoben: \(Q_{1} = Q_{2} = Q\)). Die Spannungen addieren sich:

\(U_{\mathrm{ges}} = U_{1} + U_{2}\) ⇒ \(Q/C_{\mathrm{ges}} = Q/C_{1} + Q/C_{2}\) ⇒

\[\frac{1}{C_{\mathrm{ges}}} = \frac{1}{C_1} + \frac{1}{C_2}\]

Anschaulich: Reihenschalten = Plattenabstand vergrößern. Die Gesamtkapazität ist kleiner als die kleinste einzelne. Zwei gleiche in Reihe: halbe Kapazität.

Verwechslungsgefahr: Bei Widerständen ist es genau umgekehrt (Reihe: addieren; parallel: Kehrwerte). Merke über die Physik: parallel = mehr Fläche = mehr Kapazität.

Klausur 2, Aufgabe 4 (8 BE): die vier Schaltungen

a) \(220\,\mathrm{nF}\) und \(100\,\mathrm{nF}\) parallel → \(C_{\mathrm{ges}}\)?

\(C_{\mathrm{ges}} = 220 \,\mathrm{nF} + 100 \,\mathrm{nF} = 320 \,\mathrm{nF}\). (1/1)

b) \(220\,\mathrm{nF}\) und \(100\,\mathrm{nF}\) in Reihe → \(C_{\mathrm{ges}}\)?

\(1/C_{\mathrm{ges}} = 1/220 \,\mathrm{nF} + 1/100 \,\mathrm{nF}\) ⇒ \(C_{\mathrm{ges}} = 68{,}75 \,\mathrm{nF} \approx 69 \,\mathrm{nF}\). TR-Doku: „mit solve im TR nach \(C_{\mathrm{ges}}\)". Ohne „nach \(C_{\mathrm{ges}}\)" gab es 1,5/2.

c) \(C_1\) parallel zu \(0{,}1\,\mathrm{mF}\), gesamt \(660\,\mathrm{\mu F}\) → \(C_1\)?

\(C_{1} = C_{\mathrm{ges}} - C_{2} = 660 \,\mathrm{\mu F} - 100 \,\mathrm{\mu F} = 560 \,\mathrm{\mu F}\). Achtung Einheiten: \(0{,}1\,\mathrm{mF} = 100\,\mathrm{\mu F}\). (2/2)

d) (\(44\,\mathrm{\mu F}\) in Reihe mit \(C_2\)) parallel zu \(44\,\mathrm{\mu F}\), gesamt \(66\,\mathrm{\mu F}\) → \(C_2\)?

Von außen nach innen: Der Reihenzweig muss \(66 \,\mathrm{\mu F} - 44 \,\mathrm{\mu F} = 22 \,\mathrm{\mu F}\) haben. In Reihe: \(1/22 = 1/44 + 1/C_{2}\) ⇒ \(1/C_{2} = 1/22 - 1/44 = 1/44\) ⇒ \(C_{2} = 44 \,\mathrm{\mu F}\). (2,5/3, „solve nach \(C_2\)" angeben.)

Beispiel aus dem Heft: \(30\,\mathrm{nF}\) und \(20\,\mathrm{nF}\) in Reihe (= \(12\,\mathrm{nF}\)), dazu \(10\,\mathrm{nF}\) parallel: \(C = 12 \,\mathrm{nF} + 10 \,\mathrm{nF} = 22 \,\mathrm{nF}\).

4 · Energie im Kondensator

Beim Laden muss jede weitere Ladungsportion gegen die schon vorhandene Spannung auf die Platte geschoben werden. Die Spannung wächst dabei von 0 auf \(U\). Im \(Q\)-\(U\)-Diagramm ist die Energie die Fläche unter der Geraden, ein Dreieck:

\[W = \tfrac12\,Q\,U = \tfrac12\,C\,U^2 = \frac{Q^2}{2C}\]
  • Warum \(\tfrac12\) und nicht \(Q\cdot U\): \(Q\cdot U\) wäre die Energie, wenn die ganze Ladung bei voller Spannung transportiert würde. Tatsächlich ist die Spannung am Anfang 0 und steigt erst, im Mittel also \(U/2\).
  • Herleitung im Heft über die Leistung beim Laden: \(W = \int P \mathrm{d}t = \int U_{C}\cdot I \mathrm{d}t\) von \(0\) bis \(\infty\) mit den Ladekurven ergibt \(\tfrac{1}{2}\cdot C\cdot U_{0}^{2}\). In der FS steht das Ergebnis (S. 28).
  • Die Energie steckt im elektrischen Feld zwischen den Platten. Die Formel \(E = \tfrac{1}{2}\cdot C\cdot U^{2}\) in der FS benutzt \(E\) für Energie, nicht für Feldstärke.
Rechenbeispiel: Blitzgerät

\(C = 1000\,\mathrm{\mu F}\), \(U = 300\,\mathrm{V}\): \(W = \tfrac{1}{2} \cdot 10^{-3} \,\mathrm{F} \cdot (300 \,\mathrm{V})^{2} = 45 \,\mathrm{J}\). Entlädt sich das in \(1\,\mathrm{ms}\), ist die Leistung \(45\,\mathrm{kW}\). Deshalb der Kondensator: die Batterie könnte die Leistung nicht liefern, der Kondensator sammelt langsam und gibt schnell ab.

Verwechslungsgefahr: \(W = q\cdot U\) (Lektion 2) ist die Energie eines Teilchens, das die feste Spannung \(U\) durchläuft. \(W = \tfrac{1}{2}\cdot C\cdot U^{2}\) ist die Energie des ganzen Kondensators, bei dem die Spannung während des Ladens wächst.

5 · Entladen und Laden über einen Widerstand

Qualitativ: warum exponentiell?

Geladener Kondensator, Schalter um, Widerstand \(R\) parallel. Strom \(I = U_{C}/R\), und \(U_{C} = Q/C\). Der Strom trägt Ladung ab, \(Q\) sinkt, damit \(U_{C}\), damit \(I\). Die Abnahme ist in jedem Moment proportional zum Bestand: „je mehr noch da ist, desto schneller nimmt es ab". Das ist die Definition eines exponentiellen Zerfalls, wie radioaktiver Zerfall oder Bierschaum.

Differenzialgleichung (Herleitung aus dem Heft, gibt Punkte)

  1. Maschenregel beim Entladen: \(U_{C} + U_{R} = 0\) (die beiden Spannungen gleichen sich aus; Vorzeichen je nach Zählrichtung).
  2. Einsetzen: \(Q/C + R\cdot I = 0\), und \(I = \mathrm{d}Q/\mathrm{d}t\) (Strom = Ladungsänderung pro Zeit): \(Q/C + R\cdot \mathrm{d}Q/\mathrm{d}t = 0\), also \(\mathrm{d}Q/\mathrm{d}t = -Q/(R\cdot C)\). Genau diese Form steht in der FS (S. 28): „Änderung proportional zum Bestand, mit Faktor \(-1/(RC)\)".
  3. Lösen durch Trennung der Variablen: \(\mathrm{d}Q/Q = -\mathrm{d}t/(R C)\), integrieren: \(\ln (Q/Q_{0}) = -t/(R C)\), also
\[Q(t) = Q_0\,e^{-t/(RC)},\qquad U_C(t) = U_0\,e^{-t/(RC)},\qquad I(t) = I_0\,e^{-t/(RC)}\qquad\text{mit}\quad \tau = R\,C\]
  • Zeitkonstante \(\tau = R\cdot C\). Einheiten-Check: \(\mathrm{\Omega\cdot F} = \mathrm{(V/A)\cdot(As/V)} = \mathrm{s}\). Nach \(\tau\) sind noch \(e^{-1}\) = 37 % da, nach \(5\tau\) unter 1 %. Großes \(R\) (wenig Strom) oder großes \(C\) (viel Ladung) → langsame Entladung.
  • Halbwertszeit: Basiswechsel \(e^{-t/\tau} = 2^{-t/t_{1/2}}\), Logarithmieren: \(t/\tau = (t/t_{1/2})\cdot \ln 2\) ⇒ \(t_{1/2} = \ln 2 \cdot R\cdot C \approx 0{,}69\cdot \tau\). Nach jeder Halbwertszeit halbiert sich alles (\(Q\), \(U\), \(I\)).
  • Laden (Quelle \(U_{0}\), Widerstand, leerer Kondensator): Maschenregel \(U_{0} = U_{R} + U_{C}\) → gleiche Rechnung mit Substitution → \(U_{C}(t) = U_{0}\cdot (1 - e^{-t/(R C)})\), der Strom fällt dabei wie beim Entladen: \(I(t) = I_{0}\cdot e^{-t/(R C)}\) mit \(I_{0} = U_{0}/R\) (FS S. 28).

Blau: Spannung am Kondensator. Orange: Strom. Gestrichelt: \(\tau\) (37 % bzw. 63 %) und \(t_{1/2}\). Die Fläche unter der Stromkurve ist die geflossene Ladung.

Ladung als Fläche unter \(I(t)\)

Bei konstantem Strom ist \(Q = I\cdot \Delta t\), ein Rechteck im \(I\)-\(t\)-Diagramm. Bei veränderlichem Strom ist die Ladung die Fläche unter der Kurve: \(Q = \int I(t) \mathrm{d}t\) (FS S. 24). Für die Entladekurve von \(0\) bis \(\infty\):

\[Q = \int_0^{\infty} I_0\,e^{-t/\tau}\,\mathrm{d}t = I_0\,\tau\]

Das ist die ganze Ladung, die auf dem Kondensator war. Daraus \(C = Q/U_{0}\). Alternativ im Abitur erlaubt: Kästchen zählen (Abitur 2023, 3.1: ein Kästchen = \(10\,\mathrm{\mu A}\cdot 1\,\mathrm{s} = 10\,\mathrm{\mu C}\), etwa 35 Kästchen → \(0{,}35\,\mathrm{mC}\)).

Das kostete in Klausur 2 Punkte (1c, „Ansatz unbewiesen"): \(Q = I_{0}\cdot \tau\) einfach hingeschrieben. Erwartet: \(Q = \int I \mathrm{d}t\) als Ansatz nennen, dann das Integral (im TR oder per Hand) ausrechnen. Und Einheiten: \(\mathrm{\mu A\cdot\mu s} = 10^{-12}\,\mathrm{C} = \mathrm{pC}\).

TR-Regression in die e-Form umrechnen (Klausur 2, 1b–1d; Heft)

Der TR liefert bei Exponentialregression \(y = a\cdot b^{x}\). Physik will \(I(t) = I_{0}\cdot e^{-t/\tau}\). Umrechnung: \(b^{t} = e^{t\cdot \ln b}\), Vergleich der Exponenten: \(-1/\tau = \ln b\) (pro Zeiteinheit der \(x\)-Werte), also

\[\tau = -\frac{1}{\ln b}\cdot(\text{Zeiteinheit}),\qquad\text{z. B. } b = 0{,}989949\ \text{pro}\ \mathrm{\mu s}\ \Rightarrow\ \tau = -\frac{1}{\ln(0{,}989949)}\,\mathrm{\mu s} = 99{,}0\,\mathrm{\mu s}\]

Klausur 2, Aufgabe 1: Entladung über \(R = 10\,\mathrm{k\Omega}\), Spannung am Widerstand gemessen. Umrechnung Beispiel: \(I = U/R = 6{,}1 \,\mathrm{V} / 10\,000 \,\mathrm{\Omega } = 610 \,\mathrm{\mu A}\).

So will der Lehrer die Auswertung (Bewertungsbogen Klausur 2, 1b): Vorgehen im TR (2), Umrechnung \(U \to I\) mit Beispielrechnung dokumentiert (1), Diagramm vollständig (2), Regression begründet (1), Ergebnis physikalisch sinnvoll mit Einheiten (1). Begründung der Regression: „Die Entladung ist ein Vorgang, bei dem die Abnahme proportional zum Bestand ist, also exponentiell" oder „die Werte fallen in gleichen Zeitabständen etwa um den gleichen Faktor". Nur „Punkte liegen auf einer Kurve" reicht nicht.

Oszilloskop ablesen (Heft)

Die Angaben „\(\mathrm{V/Div}\)" und „\(\mathrm{s/Div}\)" (Volt bzw. Sekunden pro Kästchen) beziehen sich auf eine Kästchenhöhe bzw. -breite. Beispiel aus dem Heft: Ladekurve, Spannungsdifferenz \(3\,\mathrm{V}\), Halbwertszeit \(70\,\mathrm{\mu s}\) abgelesen, \(R = 10\,\mathrm{k\Omega}\): \(C = t_{1/2}/(R\cdot \ln 2) = 70 \,\mathrm{\mu s}/(10 \,\mathrm{k\Omega } \cdot 0{,}693) = 1{,}01\cdot 10^{-8} \,\mathrm{F} = 10{,}1 \,\mathrm{nF}\).

6 · Klausur 2 (Aufgaben 1, 2) und Abitur mit Lösungen

Klausur 2, Aufgabe 1: Entladekurve eines Kondensators [21 BE]

a) Schaltplan [4]: Kondensator \(C\), Widerstand \(R = 10\,\mathrm{k\Omega}\) und Voltmeter parallel; Schalter, über den \(C\) vorher an der Quelle \(U_{0}\) geladen wurde. Beschriftung aller Bauteile.

b) \(I(t)\) aus Messdaten [8]: Werte in TR, \(I = U/R\) mit Beispielrechnung (\(610\,\mathrm{\mu A}\)), Diagramm \(t\) in \(\mathrm{\mu s}\) gegen \(I\) in \(\mathrm{\mu A}\) mit Punkten, exponentielle Regression (Begründung: Abnahme proportional zum Bestand), TR: \(y = 622{,}6\cdot 0{,}989949^{x}\), physikalisch: \(I(t) = 622{,}6 \,\mathrm{\mu A} \cdot 0{,}989949^{t/\mathrm{\mu s}}\). Kontrollergebnis stand in der Aufgabe.

c) \(Q\) und \(C\) [5]: \(Q = \int _{0}^{\infty} I(t) \mathrm{d}t = I_{0}\cdot \tau\) mit \(\tau = -1 \,\mathrm{\mu s}/\ln (0{,}989949) = 99{,}0 \,\mathrm{\mu s}\): \(Q = 622{,}6 \,\mathrm{\mu A} \cdot 99{,}0 \,\mathrm{\mu s} = 61{,}6 \,\mathrm{nC}\). \(C = Q/U_{0} = 61{,}6 \,\mathrm{nC} / 6{,}1 \,\mathrm{V} = 10{,}1 \,\mathrm{nF}\) (oder \(C = \tau /R = 9{,}9 \,\mathrm{nF}\); beides im Rahmen der Messgenauigkeit).

d) Anderer Kondensator, \(I(t) \propto 0{,}90484^{t/\mathrm{ms}}\) [4]: \(\tau = -1 \,\mathrm{ms}/\ln (0{,}90484) = 10{,}0 \,\mathrm{ms}\) ⇒ \(C = \tau /R = 10 \,\mathrm{ms} / 10 \,\mathrm{k\Omega } = 1{,}0 \,\mathrm{\mu F}\). Die Startspannung braucht man gar nicht, weil \(\tau\) nur von \(R\) und \(C\) abhängt.

Klausur 2, Aufgabe 2: Kondensator mit Dielektrikum (Öl) [11 BE]

a) [1]: Die Kapazität steigt. Begründung dazuschreiben („gib an!"): Polarisation des Öls erzeugt ein Gegenfeld, bei gleicher Ladung sinkt die Spannung.

b) [2]: \(C_{0} = \varepsilon _{0}\cdot A/d = 8{,}854\cdot 10^{-12} \cdot 0{,}1/0{,}06 \,\mathrm{F} = 1{,}48\cdot 10^{-11} \,\mathrm{F}\), bestätigt.

c) [5]: \(t_{1/2} = \ln 2 \cdot R \cdot C_{\mathrm{Öl}}\) ⇒ \(C_{\mathrm{Öl}} = t_{1/2}/(R\cdot \ln 2) = 2{,}08\cdot 10^{-3} \,\mathrm{s} / (10^{8} \,\mathrm{\Omega } \cdot 0{,}693) = 3{,}00\cdot 10^{-11} \,\mathrm{F}\). \(\varepsilon _{r} = C_{\mathrm{Öl}}/C_{0} = 3{,}00/1{,}48 = 2{,}03\) (Öl laut Tabelle 2,2, passt).

d) [3]: Füllhöhe \(f\), Plattenhöhe \(h = 1\,\mathrm{m}\): \(C = C_{0}\cdot (h - f)/h + C_{\mathrm{Öl}}\cdot f/h\) ⇒ \(f(C) = h\cdot (C - C_{0})/(C_{\mathrm{Öl}} - C_{0})\). 7 · Analogie-Trainer

Kondensator ↔ Wassertank

Spannung = Füllhöhe, Ladung = Wassermenge, Kapazität = Grundfläche des Tanks: \(Q = C\cdot U\) wie Volumen = Fläche · Höhe.

Parallel ↔ Tanks nebeneinander

Gleiche Füllhöhe (\(U\)), Grundflächen addieren sich (\(C\)). Reihe: wie ein schmalerer Durchlass, Gesamtkapazität kleiner.

Entladen ↔ Tank mit Loch

Abfluss ∝ Füllhöhe → Füllhöhe sinkt exponentiell. Enger Abfluss (großes \(R\)) oder großer Tank (großes \(C\)) → langsam: \(\tau = R\cdot C\).

Energie ↔ Wasser hochpumpen

Je voller, desto höher muss man heben. Mittlere Höhe \(U/2\), deshalb \(W = \tfrac12\cdot Q\cdot U\).

Dielektrikum ↔ Schwamm im Tank

Bei gleicher Wassermenge steigt der Pegel weniger: mehr Fassungsvermögen pro Höhe. Die Analogie hinkt: physikalisch ist es das Gegenfeld der Dipole.

Wo die Analogie bricht

Wasser hat kein Vorzeichen. Die beiden Platten tragen \(+Q\) und \(-Q\); „die Ladung des Kondensators" meint den Betrag auf einer Platte.

8 · Checkfragen und Aufgaben

Checkfrage 1: Warum ist bei der Reihenschaltung die Ladung auf beiden Kondensatoren gleich?

Die Verbindung zwischen den beiden inneren Platten ist von außen isoliert. Dort kann keine Ladung hinein oder heraus, nur verschoben werden: Was auf der einen inneren Platte als \(+Q\) sitzt, fehlt der anderen als \(-Q\). Beide Kondensatoren tragen denselben Betrag \(Q\).

Checkfrage 2: Ein geladener, abgeklemmter Kondensator wird auseinandergezogen. Was passiert mit \(Q\), \(C\), \(U\), \(E\) und \(W\)?

\(Q\) konstant (abgeklemmt). \(C = \varepsilon _{0}A/d\) sinkt. \(U = Q/C\) steigt. \(E = \sigma /\varepsilon _{0} = Q/(\varepsilon _{0}A)\) bleibt gleich (hängt nicht von \(d\) ab). \(W = Q^{2}/(2C)\) steigt: die Arbeit, die man gegen die Anziehung der Platten verrichtet, steckt jetzt im Feld.

A1: \(C = 4{,}7\,\mathrm{\mu F}\) wird über \(R = 22\,\mathrm{k\Omega}\) entladen, \(U_0 = 9{,}0\,\mathrm{V}\). \(\tau\), \(t_{1/2}\), \(I_0\), \(Q_0\), \(W_0\), und wann sind noch 10 % der Spannung da?

\(\tau = R C = 22\,000 \,\mathrm{\Omega } \cdot 4{,}7\cdot 10^{-6} \,\mathrm{F} = 0{,}103 \,\mathrm{s}\); \(t_{1/2} = \ln 2 \cdot \tau = 0{,}072 \,\mathrm{s}\); \(I_{0} = U_{0}/R = 0{,}41 \,\mathrm{mA}\); \(Q_{0} = C\cdot U_{0} = 42 \,\mathrm{\mu C}\) (Kontrolle: \(I_{0}\cdot \tau = 0{,}41 \,\mathrm{mA} \cdot 0{,}103 \,\mathrm{s} = 42 \,\mathrm{\mu C}\) ✓); \(W_{0} = \tfrac{1}{2}\cdot C\cdot U_{0}^{2} = 0{,}19 \,\mathrm{mJ}\); 10 %: \(e^{-t/\tau} = 0{,}1\) ⇒ \(t = \tau \cdot \ln 10 = 0{,}24 \,\mathrm{s}\).

A2: TR-Regression liefert \(I(t) = 2{,}4\,\mathrm{mA}\cdot 0{,}9512^{t/\mathrm{ms}}\). \(\tau\), \(Q\) und \(C\) bei \(U_0 = 12\,\mathrm{V}\)?

\(\tau = -1 \,\mathrm{ms} / \ln (0{,}9512) = 20{,}0 \,\mathrm{ms}\); \(Q = I_{0}\cdot \tau = 2{,}4 \,\mathrm{mA} \cdot 20 \,\mathrm{ms} = 48 \,\mathrm{\mu C}\); \(C = Q/U_{0} = 4{,}0 \,\mathrm{\mu F}\); Widerstand: \(R = \tau /C = 5{,}0 \,\mathrm{k\Omega }\) (Kontrolle: \(U_{0}/I_{0} = 12 \,\mathrm{V}/2{,}4 \,\mathrm{mA} = 5 \,\mathrm{k\Omega }\) ✓).

A3: Plattenkondensator \(A = 200\,\mathrm{cm^2}\), \(d = 2{,}0\,\mathrm{mm}\), \(U = 100\,\mathrm{V}\), Quelle bleibt angeschlossen. Dann wird eine Plexiglasplatte (\(\varepsilon_r = 3{,}4\)) eingeschoben. \(Q\) vorher/nachher?

\(C_{0} = \varepsilon _{0}\cdot 0{,}020 \,\mathrm{m^2}/0{,}0020 \,\mathrm{m} = 8{,}85\cdot 10^{-11} \,\mathrm{F} = 88{,}5 \,\mathrm{pF}\); \(Q_{0} = C_{0}\cdot U = 8{,}85 \,\mathrm{nC}\). Mit Plexiglas: \(C = 3{,}4\cdot C_{0} = 301 \,\mathrm{pF}\), \(U\) bleibt \(100\,\mathrm{V}\), \(Q = 30{,}1 \,\mathrm{nC}\): es fließen \(21\,\mathrm{nC}\) nach. (Wäre die Quelle abgeklemmt: \(Q\) bleibt \(8{,}85\,\mathrm{nC}\), \(U\) fällt auf \(100\,\mathrm{V}/3{,}4 = 29\,\mathrm{V}\).)

A4: Drei Kondensatoren: \(10\,\mathrm{\mu F}\) und \(40\,\mathrm{\mu F}\) in Reihe, dazu \(12\,\mathrm{\mu F}\) parallel. \(C_{\mathrm{ges}}\)? Ladung bei \(20\,\mathrm{V}\)?

Reihe: \(1/C = 1/10 + 1/40 = 5/40\) ⇒ \(8\,\mathrm{\mu F}\). Parallel: \(8 + 12 = 20 \,\mathrm{\mu F}\). \(Q = 20 \,\mathrm{\mu F} \cdot 20 \,\mathrm{V} = 400 \,\mathrm{\mu C}\).

9 · Nicht in der Formelsammlung (auswendig)

  • Kapazität als Steigung im \(Q\)-\(U\)-Diagramm; \(1\,\mathrm{F} = 1\,\mathrm{As/V}\); typische Werte \(\mathrm{pF}\) bis \(\mathrm{mF}\); Einsatzmöglichkeiten.
  • Herleitung \(C = \varepsilon _{0}A/d\) aus \(\sigma = Q/A\), \(\sigma = \varepsilon _{0}E\), \(E = U/d\). Begründung \(C \propto A\), \(C \propto 1/d\); Auswertung über das \(C\)-(\(1/d\))-Diagramm, \(\varepsilon _{0} = \text{Steigung}/A\).

  • Zwei Fälle: Quelle getrennt (\(Q\) konstant) vs. angeschlossen (\(U\) konstant).

  • Herleitungen Reihe/Parallel (gleiche Spannung bzw. gleiche Ladung); Merkregel parallel = Fläche, Reihe = Abstand; Gegensatz zu Widerständen.
  • Energie: Fläche unter der \(Q\)-\(U\)-Geraden, warum \(\tfrac12\); \(W = \tfrac{1}{2}Q U = Q^{2}/(2C)\) (FS hat nur \(\tfrac{1}{2}C U^{2}\)).

10 · Merksätze, Verwechslungen, Fortschritt

  1. \(C = Q/U\): Ladung pro Volt, nur von der Bauform abhängig. Platten: \(C = \varepsilon _{0}\varepsilon _{r}A/d\).
  2. Dielektrikum schwächt das Feld um \(\varepsilon _{r}\) und erhöht \(C\) um \(\varepsilon _{r}\). Erst fragen: Quelle dran oder nicht?
  3. Parallel addieren (mehr Fläche), Reihe Kehrwerte (mehr Abstand). Nebeneinander gefüllt = parallel.
  4. \(W = \tfrac{1}{2}C U^{2}\), weil die Spannung beim Laden mitwächst.
  5. Entladen: Abnahme ∝ Bestand ⇒ \(e^{-t/R C}\); \(\tau = R C\), \(t_{1/2} = \ln 2\cdot R C\), \(Q = I_{0}\tau\).
